# 精简 9.4.0.131 静态资源(词典/帮助/插件/sdk-all.js)

- **时间**:2026-08-11
- **项目路径**:`F:\JsWorkSpace\very-office`

## 背景

离线分发包体积 2.1GB(打包 zip 约 1.7GB)，用户要求缩小压缩包。字体的"打开慢"问题
经调研确认已由 2026-08-10 的按需加载机制解决(打开 docx→bin 只抓文档引用字体 +
`OO_ALWAYS_FONTS` 16 个兜底；仅 PDF 导入/导出全量抓 267 个字体），无需再做异步方案；
**字体全部保留不动**。

## 执行内容

新脚本 `tools/trim-9.4.0-assets.py`(幂等；默认 dry-run,`--apply` 真删；删除前逐项目录并统计大小）:

1. **词典**:`9.4.0.131/vendor/dictionaries/` 只留 en_US/en_GB/de_DE/fr_FR/es_ES/ru_RU/pt_BR
   + README.md，删 43 个语言目录(含 55.6M 的 tr_TR)。词典按语言目录运行时按需加载
   (`sdk-all-min.js` 内 `urlDictionaries = "../../../../dictionaries/"`)，删目录无代码依赖；
   被删语言的拼写检查/同义词/断字静默失效。
2. **离线帮助**：删 5 个编辑器 `web-apps/apps/<editor>/main/resources/help/`(共 564M)。
   后果：编辑器 Help 菜单/F1 打开的帮助页 404（已确认接受）。
3. **插件**:`sdkjs-plugins/content/` 只留 `assets/office-config.js` pluginsData 启用的 10 个
   (ai/zhipu/drawio/highlightcode/ocr/photoeditor/translator/zoom/languagetool/mathpix),
   删除其余 42 个(idphoto 94.8M、cvbuilder 51.2M、onlydraw 27M、lizardtypst 24.4M 等）;
   各保留插件内的 `deploy/`(*.plugin 打包产物，运行时无引用，drawio 的就有 47.7M）一并删。
   注意：插件公共运行库在 `sdkjs-plugins/v1/`(content 的同级，不在 content 内），不受裁剪影响。
4. **sdkjs**：删 `sdkjs/<word|cell|slide|visio>/sdk-all.js` 未压缩版(共 111M)。运行时全部只加载
   `sdk-all-min.js`（各编辑器 app.js 的 requirejs 路径、embed/index_loader.html 均只引用 -min),
   未压缩版仅被未使用的 preload.html/cache-scripts.html 引用。

执行后按约束把 `9.4.0.131/vendor/document_editor_service_worker.js` 的
`g_cacheName`/`g_fifoCacheName` 从 `_v15` 提到 `_v16`。
(`sdkjs/common/serviceworker/document_editor_service_worker.js` 是无 `_vN` 后缀的上游原件，
非注册用副本，未动。)

## 字体 .br/.gz 异常(需知悉)

裁剪执行期间，`fonts/` 下全部 370 个 `.br`/`.gz` 预压缩变体被**本任务之外的操作**删除
(目录 mtime 16:04；删除集合精确等于全部 br+gz;267 个 raw 字体文件完好，git 索引中对应
blob 仍在，`git checkout-index -f -- <path>` 可逐字节恢复)。
影响：仅 nginx `gzip_static`/`brotli` 预压缩部署不再直接命中字体压缩变体；
`python -m http.server` 等普通静态服务本来就不使用它们。也可用 brotli/gzip 对 raw 重新生成。
顺带效果：fonts 目录从 661M 降到 285M(raw 完整，功能无损)。
