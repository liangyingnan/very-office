# 修复 9.4.0.131 api.js 缺失 createConnector 导致 AI 初始化失败

- **时间**：2026-08-12
- **项目路径**：`F:\JsWorkSpace\very-office`（同步影响 `F:\JsWorkSpace\onlyoffice-ai-word-demo`）

## 背景 / 问题

onlyoffice-ai-word-demo 的 AI 层（`office-wrapper/ai/editor-connector.js`）依赖
`docEditor.createConnector()`（`Asc.EditorConnector`，外部插件通道）写回文档。
2026-08-12 更新离线资源后，应用弹窗报错：

> AI 初始化失败：编辑器尚未就绪或不支持 createConnector

## 根因

本项目的 `9.4.0.131/vendor/web-apps/apps/api/documents/api.js` **不含** `Asc.EditorConnector`
类与 `DocEditor.createConnector` 入口（整文件无 `Connector` 字样）。
旧资源（`F:\JsWorkSpace\ruixiaozhao-Onlyoffice\9.4.0\vendor\...\api.js`，9.4.0 布局）在
api.js 末尾内置了完整实现：928–1156 行的 `(function (m) { ... m.Asc.EditorConnector = e })(window)`
IIFE + `_createConnector()` + DocEditor 返回对象的 `createConnector` 字段。
此前可用的 zip 安装副本应来自带该实现的构建；本次从 very-office 同步的新资源 api.js 是未含实现的版本。

编辑器内核侧（`sdkjs/word/sdk-all-min.js`）通道支持完好：
`onExternalPluginMessage`（7 处）、`pluginMethod_GetSelectedText`、`GroupActions` 均存在，
缺的只是 api.js 侧的连接器封装。

## 修复

把 9.4.0 api.js 的连接器代码块原样移植进 9.4.0.131 api.js（两文件结构对齐，`iframe` 等同名闭包变量行号一致）：

1. 在 DocEditor 的 `return { ... }` 之前插入旧文件 928–1160 行
   （EditorConnector IIFE + `_createConnector(settings)`，依赖闭包变量 `iframe`，自包含）。
2. 在 DocEditor 返回对象首行加入 `createConnector : _createConnector,`。
3. `node --check` 语法校验通过。

已打补丁的副本（每处均留有 `api.js.bak-createconnector` 备份）：

- `9.4.0.131/vendor/web-apps/apps/api/documents/api.js`（本仓库主副本）
- `office-local/9.4.0.131/vendor/web-apps/apps/api/documents/api.js`（打包分发副本）
- `C:\Users\liang\AppData\Roaming\onlyoffice-ai-word-demo\office-local\9.4.0.131\...\api.js`（demo 运行副本）

同时按 SW 约束把两处 `9.4.0.131/vendor/document_editor_service_worker.js`
的 `_v19` 升为 `_v20`（demo 侧启动时会清 SW/CacheStorage，无需处理）。
