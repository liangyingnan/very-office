## 四、构建方式
- **sdkjs（通常无需重建）**：已随仓库携带预编译 `sdkjs/word/sdk-all-min.js`；如需重编 `cd 9.4.0/vendor/sdkjs/build && python build.py`，产物 `deploy/sdkjs/` 同步回 `vendor/sdkjs/`（**勿覆盖 `common/wasm/x2t/`**）。
- **web-apps（必须构建）**：纯源码，需 Grunt：
  ```bash
  cd 9.4.0.131/vendor/web-apps/build
  npm install
  npx grunt deploy-documenteditor deploy-spreadsheeteditor \
              deploy-presentationeditor deploy-pdfeditor deploy-visioeditor deploy-common-component
  ```
  产物 `web-apps/deploy/web-apps/` 同步回 `../9.4.0.131/vendor/web-apps/`（`cp -r deploy/web-apps/* ../web-apps/`），确保 `apps/api/documents/api.js` 与各编辑器 `main.js` 存在。
- **插件（静态，无需构建）**：`../9.4.0.131/vendor/sdkjs-plugins/content/<plugin>/` 直接作为静态资源；在 `office-config.js` 的 `pluginsData` 登记 `.../config.json` 即默认启用。drawio guid：`asc.{DB38923B-A8C0-4DE9-8AEE-A61BB5C901A5}`。
- **plugins-store（可选）**：`../9.4.0.131/vendor/plugins-store/build.bat`（closure compiler）构建 `code_min.js`；离线编辑不依赖它。
- **x2t.wasm（已内置，无需编译）**：位于 `../9.4.0.131/vendor/sdkjs/common/wasm/x2t/`，9.4 版。
